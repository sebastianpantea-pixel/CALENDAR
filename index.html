📅 Family Calendar
Configurare rapidă — 2 pași simpli.
1
Deschide console.cloud.google.com și loghează-te cu contul Google
2
Click Select a project → New Project, dă un nume, Create
3
APIs & Services → Enable APIs → caută Google Calendar API → Enable
4
Credentials → + Create Credentials → API Key → copiaz-o jos
Salvată local pe tabletă. Nu se trimite nicăieri.
Dacă calendarul "Family" e pe contul tău, ID = emailul tău Gmail.
Altfel: Google Calendar → ⚙ lângă calendar → Settings → Calendar ID
